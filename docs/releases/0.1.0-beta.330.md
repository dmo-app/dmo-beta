# 0.1.0-beta.330 — Remover reparadores nas Definições das Boquilhas (DMO-292)

Branch `claude/project-thread-l0wuqi`. Uso diário do Diogo (21/10/2026).

- **Remover um reparador.** «Não existe forma de remover ou editar reparadores.» Cada linha da tabela dos reparadores tem «Opções» › «Remover reparador» (sem botões espalhados na linha), que abre uma janela de confirmação. Numa só gravação, as saídas que apontavam para ele largam a ligação e guardam o nome (a que já o tinha guardado fica como estava), as máquinas que o usavam ficam sem reparador e o reparador sai (`DeleteBqRepairerHandler`). A FK das saídas continua Restrict: a base recusa apagá-lo sem isto.
- **Mudar o nome.** Já existia (clicar no nome, grava ao sair do campo); o cabeçalho da tabela passa a dizê-lo: «Reparador · clique no nome para o mudar».
- **Testes.** Testes novos para o handler (em memória e no PostgreSQL, com a FK) e para a página; o teste do nome no próprio valor passa a aceitar o «Remover reparador» das «Opções» na linha, mas nenhum botão de gravar (registo A-0013, ok-do-diogo).

Validação: CI local (`scripts/ci/ci-local.sh`) sobre a main.
