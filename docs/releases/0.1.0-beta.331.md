# 0.1.0-beta.331 — O Excel das Boquilhas recebe cada movimento (DMO-293)

Branch `claude/project-thread-l0wuqi`. Pedido do Diogo (21/10/2026): o chefe quer o registo das Boquilhas no Excel «Saida Entrada BQ 2026.xlsx»; «cada registo que faço passa guardar a informação nesse excel que está numa pasta do pc».

- **Escolher o Excel.** Nas Definições das Boquilhas, o cartão «Excel das Boquilhas» escolhe o ficheiro uma vez em cada computador (Chrome ou Edge, File System Access API, guardado só no navegador, como a pasta dos PDFs). «Opções» tem «Atualizar o Excel agora» e «Deixar de usar».
- **Escrever.** Depois de cada gravação nas Boquilhas (e ao abri-las), o navegador pergunta a versão dos movimentos (`?handler=ExcelVersao`); se mudou, envia o ficheiro (`?handler=Excel`) e grava por cima o que volta. O ficheiro nunca fica no servidor.
- **O formato do Diogo.** Um separador por mês; cada dia em 5 linhas a partir da linha 4; cada máquina em 4 colunas (Ref, Sai, Ent, N.Fat) com o código na linha 1. Ref = BQ/lote; Sai = saídas; Ent = entradas reparadas; N.Fat = entradas sem reparação (à espera da confirmação do Diogo). Vários movimentos no dia escrevem-se como soma (=23+10). Escrevem-se todos os dias desde o dia em que o ficheiro foi escolhido. A app só volta a mexer nas linhas que ela própria escreveu (o navegador guarda quais) e usa as linhas livres do dia; as linhas escritas à mão, os dias anteriores e o resto do ficheiro ficam como estão. Uma correção ou anulação limpa só a linha da app. Um mês sem separador cria-se a partir de outro mês do livro, com as datas e os dias da semana. Com o Excel aberto o Windows não deixa gravar: a app avisa e tenta no registo seguinte.
- **Como.** `BqExcelPlano` (Core) monta os dias a partir dos movimentos do Histórico; `BqExcelLivro` (Infrastructure) mexe só nos valores das células, no XML do .xlsx, sem bibliotecas novas; a cadeia de cálculo sai e o Excel recalcula ao abrir.
- **Testes.** Testes novos para o livro (escrita, soma, limpeza, mês novo, avisos, ficheiro que não é Excel), para as páginas (cartão, versão, ficheiro devolvido, recusas) e um teste de browser novo no CI local (`tests/visual/excel_bq_browser.py`). Validado também no ficheiro real do Diogo (aberto no LibreOffice, fórmulas recalculadas).

Validação: CI local (`scripts/ci/ci-local.sh`) sobre a main.
